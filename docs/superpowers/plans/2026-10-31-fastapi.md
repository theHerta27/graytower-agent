# FastAPI Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前研发助手改为 FastAPI 接口和严格请求模型，保持前端与任务行为，验证后同步公开材料。
**Architecture:** API 模型独立于业务执行；原 Workbench、DevelopmentTask 和交付模块继续复用。FastAPI 显式声明各操作，统一错误处理；保留纯 ASGI 来源和大小检查。模型执行仍由原后台驱动管理。
**Tech Stack:** Python 3.11, FastAPI, Pydantic 2, LangGraph, React, SQLite.
**Spec:** docs/superpowers/specs/2026-10-31-fastapi.md

## Global Constraints
- 无新增收费模型调用；Herta、原游戏、历史证据不修改。
- 保持接口 URL、JSON 成功格式、error 字段和业务审批要求。
- 请求最大 1,100,000 字节；多余字段及授权类型不自动转换。
- 博客所有日期字段保持不变；简历只补灰塔 FastAPI 技术栈。

## Review Focus
- 校验错误不回显原始私密字段；非法参数不得创建任务或启动模型。
- 字符串/数字不能代替 true 布尔授权。
- 文档及读接口不调用模型；来源检查不能被文档入口绕过。
- 请求体上限同时覆盖分块传输；未知操作仍为 404。
- 暂停恢复、版本失效与合入撤销沿用原业务规则。
