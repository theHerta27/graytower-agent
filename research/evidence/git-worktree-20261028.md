## 审查和故障复现

独立审查没有报告 Critical，提出 5 项 Important；均先复现失败，再修改并验证：

1. 模型运行期间的页面读取被长时文件锁挡住：分开运行占用与短时文件锁，状态可读，人工写入仍拒绝。
2. 分支已冻结、元数据未更新：读取冻结意图，核对实际提交、索引和文件后补记。
3. 工作树已删除、归档标记未更新：从已保存归档与 Git 登记核对，恢复只读报告。
4. 过期冲突无结束路径：提供绑定现场摘要的显式废弃，保存人工内容和索引。
5. 已采用任务必须先撤销才能清理：允许保留已采用修复后归档，仍阻止未完成操作。
