# NPC Agent 源码说明

面向玩家：在营地交谈、了解支援选项、确认选择，在真实战斗中看到效果；战后分享战报，角色只记住当前存档中自己获知的经历。

## 从哪里读

- `service.py` 的 `NPCService`：对话、选择、恢复和记忆查询入口。
- `workflow.py`：LangGraph 对话与行动流程。
- `contracts.py`：存档/角色范围与结构化决定。
- `store.py`：对话、行动身份、回执和角色记忆。
- `world_client.py`：NPC 与玩家各自可用的游戏接口。
- `demo.py`：营地演示服务；页面在 `frontend/src/CampPage.tsx`。

## 复用了什么

LangGraph 组织流程与暂停/恢复，模型路径复用共享 LangChain/DeepSeek 接入。实际奖励、玩家授权、行动幂等和战斗由同级 `graytower-game` 仓库负责；模型不能自行发放奖励。响应丢失时使用同一行动 ID 查询/重试收据，不重复发奖。

## 如何使用与当前限制

双击根目录 `开始剧情演示.cmd`，打开营地页面，按中文使用手册体验完整流程。当前可演示版本采用明确标注的离线台词，世界支援、战斗与记忆是真实执行。真实模型自由对话尚未验收；角色记忆当前使用范围过滤和文本查询，未引入向量数据库。
